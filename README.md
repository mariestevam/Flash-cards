🧠 AnatoCards — Flashcards de Anatomia Humana

O AnatoCards é uma plataforma web interativa desenvolvida para auxiliar estudantes no aprendizado e na revisão de Anatomia Humana por meio de flashcards.

O projeto foi pensado para tornar o estudo mais dinâmico, permitindo testar conhecimentos, revisar conteúdos e acompanhar o progresso ao longo dos estudos.

✨ Funcionalidades

- 📇 217 flashcards de Anatomia Humana
- 📚 Conteúdos organizados em 6 módulos
- 🔄 Cards interativos com efeito de virar
- ✅ Marcação de respostas:
  - ❌ Errei
  - 🔄 Revisar
  - ✅ Acertei
- 📊 Acompanhamento do progresso de estudo
- 🔎 Pesquisa por termos e conteúdos
- 📋 Visualização em formato de lista
- 🎲 Embaralhamento dos flashcards
- ⌨️ Atalhos de teclado para facilitar a navegação
- 💾 Salvamento do progresso no navegador utilizando "localStorage"
- 📱 Interface responsiva para diferentes tamanhos de tela

📚 Conteúdos

O projeto reúne flashcards sobre:

- Introdução à Anatomia
- Sistema Esquelético
- Sistema Articular
- Sistema Circulatório
- Sistema Respiratório
- Sistema Muscular

🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Google Fonts
- LocalStorage

🎯 Objetivo

O objetivo do projeto é criar uma ferramenta simples, visual e interativa que facilite a memorização, revisão e preparação para provas de Anatomia Humana.

Além de ser uma ferramenta de estudo, o projeto também representa uma aplicação prática de conceitos de desenvolvimento web, JavaScript, manipulação do DOM, armazenamento local e design responsivo.

🚀 Como executar

O projeto pode ser executado diretamente no navegador.

1. Clone este repositório:

git clone https://github.com/seu-usuario/anatocards.git

2. Abra o arquivo "index.html" no navegador.

Não é necessário instalar dependências para executar a versão atual.
